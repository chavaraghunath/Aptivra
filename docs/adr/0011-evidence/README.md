# ADR-0011 arithmetic evidence

`smollm2-arithmetic.json` was generated from the immutable, already-cached
`HuggingFaceTB/SmolLM2-360M` snapshot at revision
`f8027fd0eaeea54caa13c31d31b9fdc459c38b49`. The script reads only
`config.json`, tokenizer assets, and safetensors metadata; it does not load the model, use the
network, or train. It validates the stock architecture, tied-head representation, tokenizer class,
special-token contract, absence of a pad/chat template, and hashes every tokenizer asset used by
the decision.

From the repository root, reproduce it with the shared virtual environment:

```bash
snapshot="$HOME/.cache/huggingface/hub/models--HuggingFaceTB--SmolLM2-360M/snapshots/f8027fd0eaeea54caa13c31d31b9fdc459c38b49"
PYTHONPATH="$PWD" /Users/raghunath/code/personal/Aptivra/.venv/bin/python \
  docs/adr/0011-evidence/compute_smollm2_arithmetic.py "$snapshot"
```

The committed JSON is the script's sorted, indented stdout. Its hashes make a wrong or changed
cache snapshot visible. Static parameter-state arithmetic deliberately excludes activations,
allocator state, kernels, and temporary tensors; it cannot establish that a recipe fits. The ADR
therefore requires a measured MPS pilot before training.

`candidate-matrix-arithmetic.json` extends that evidence across all seven ADR-0008 candidates. It
is generated by `compute_candidate_matrix.py` from immutable cached `config.json` files, using
meta-device model construction so no weight tensor is loaded. The script counts rank-16 LoRA
parameters from the actual projection shapes exposed by the pinned Transformers implementation
and binds the five completed full-fine-tuning peaks to their immutable ADR-0008 records. It never
downloads a missing model: a missing snapshot is emitted as `not_computed_config_not_cached`, with
no inferred parameter or memory values.

From the repository root, reproduce the candidate matrix offline with:

```bash
PYTHONPATH="$PWD" /Users/raghunath/code/personal/Aptivra/.venv/bin/python \
  docs/adr/0011-evidence/compute_candidate_matrix.py
```

The replay projection adds the documented 32,768,000-byte cache upper bound to the ADR-0008
measured peak. The online-EWC projection adds one fp32 Fisher and one fp32 anchor (`8P` bytes).
Where ADR-0008 has no completed peak, the artifact reports only static lower bounds: `16P` for
full-fp32 AdamW and `24P` with online EWC. A lower bound above the cap proves non-fit; a lower bound
below it does not prove fit. Aptivra's own static figures are likewise arithmetic, not measured
runtime peaks.
